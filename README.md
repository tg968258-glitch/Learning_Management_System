# Learning Management System (LMS)

A web-based Learning Management System (LMS) designed to provide an interactive platform for students, teachers, and admin. The system enables course management, student enrollment, assignment submission, progress tracking, and AI-powered learning recommendations.

---

## Project Overview

The Learning Management System simplifies the teaching and learning process by allowing users to:

- Manage courses and learning materials
- Enroll students in courses
- Submit and review assignments
- Track learning progress
- Generate AI-based course recommendations
- Manage users through an admin dashboard

---

## Database Entities

- Students
- Teachers
- Courses
- Enrollments
- Assignments
- Learning History

---

## REST API Endpoints

### 1. Get All Courses
```
GET https://lms.com/api/v1/courses
```

### 2. Get Student by ID
```
GET https://lms.com/api/v1/students/{id}
```

### 3. Enroll Student in Course
```
POST https://lms.com/api/v1/enrollments
```

### 4. Get Assignment History
```
GET https://lms.com/api/v1/assignments/history
```

### 5. AI Learning Recommendations
```
POST https://lms.com/api/v1/ai/recommendations
```
